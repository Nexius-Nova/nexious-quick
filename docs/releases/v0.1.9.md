## 自动同步修复

- 应用、Chrome / Edge / Brave 收藏夹、已选本地目录统一处理新增、修改和删除。
- 后台在每轮完成后间隔 15 秒再次检查，驻留托盘时继续运行；应用自动同步遵循设置开关。
- 修复软件卸载后残留条目、失效快捷方式被重新导入，以及同步完成后当前搜索结果不刷新的问题。
- 保留其他浏览器或重叠目录中仍然存在的条目；扫描失败、目录离线或达到索引上限时保护未完整扫描的数据。
- 同步结果显示实际新增、更新、移除数量。

## 升级保留数据

- 应用内「检查更新」只查询版本，不重置或清空数据。
- 新版继续使用原数据目录和数据库，保留启动项、别名、自定义描述和图标、启用状态、设置及搜索历史。
- 旧版首次迁移前自动备份完整数据库（含已提交但尚未写回主文件的数据），备份位置：`%APPDATA%\com.nexious.quick\backups\nexious-before-0.1.9.db`。
- 安装包不包含开发电脑的数据库。升级迁移不删除已有条目；正常自动同步仍会更新或移除源数据中已变更的自动导入项。

## 安装

- Windows x64 EXE：安装向导，推荐普通用户使用。
- Windows x64 MSI：适用于原先通过 MSI 安装的用户或企业部署。
- 退出正在运行的应用，使用与原安装相同类型的安装包直接覆盖安装，无需先卸载或清理数据。
- `SHA256SUMS.txt` 提供安装包校验值。
